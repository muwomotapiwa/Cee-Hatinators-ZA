# Sprint 004A Requirements - Client Decision Review and Scope Lock

## Sprint Goal

Create a clear decision-review and scope-lock documentation pack that can be used to approve the MVP build scope before implementation starts.

Sprint 004A is documentation-only. It does not start implementation.

## In Scope

- Create a decision register from Sprint 003 open questions and proposed defaults.
- Create a proposed MVP scope lock.
- Create a deferred post-launch scope list.
- Create a simple client approval checklist.
- Create an implementation readiness gate.
- Update state, decisions, risks, and questions documentation.
- Recommend the next sprint based on approval readiness.

## Out of Scope

- Application code changes.
- Firestore rules changes.
- Firebase Cloud Functions.
- Payment backend or Stripe webhook.
- Admin dashboard.
- Product migration to Firestore.
- Product variants in code.
- Inventory logic in code.
- Wishlist persistence.
- Returns implementation.
- Saved addresses.
- Newsletter automation.
- UI redesign.
- Any application feature.
